ABOUT / 01

從不同材料出發，
用同一套科學思維

我是謝宗元，專注於化工、材料與製程之間的連結。

目前任職於工業技術研究院，累積約五年化工、材料研發與製程相關經驗。從 PCB 電子材料、PU 聚氨酯與環氧樹脂複合材料，到隱形眼鏡光學材料及有機半導體功能層，逐步建立跨領域的技術視野。

不同材料系統看似各有專門語言，核心問題卻常常相通：材料本身如何影響製程窗口？製程條件如何改變結構與性能？量測數據又能如何幫助我們排除假設、縮小問題範圍？

我相信，好的技術判斷不是猜中答案，而是建立一條能被觀察、驗證與重複的推理路徑。

HOW I FRAME A TECHNICAL QUESTION

研究方向 → 技術挑戰 → 方法設計 → 驗證思路

用清楚的分析脈絡，說明問題如何被拆解、變因如何被觀察，以及哪些證據能支持下一步判斷。

METHOD EXAMPLES · NOT CLIENT CASES
CASE FRAMEWORK 01

高分子複合材料與配方研究

當材料性能不如預期，先確認是配方比例、界面相容性、固化／發泡條件，還是測試方法造成差異。

示意
01 / DEFINE界定性能
02 / VARY設定變因
03 / MEASURE量測比較
04 / VERIFY重複驗證
查看分析框架
可觀察項目：原料批次、配方比例、混合／固化條件、材料密度或力學／熱性質等。
驗證思路：建立基準組，控制一次主要變因，記錄測試方法與環境，再評估結果是否可重現。實際指標需依材料系統及應用需求決定。
CASE FRAMEWORK 02

光學量測與品質分析

量測結果出現偏移時，分離樣品差異、設備／校正、環境條件及判定門檻的影響。

示意
01 / CHECK確認量測
02 / BASELINE建立基準
03 / COMPARE比對異常
04 / DECIDE定義判準
查看分析框架
可觀察項目：量測重複性、校正狀態、樣品定位、環境光／溫度、影像或光譜特徵。
驗證思路：使用基準樣品與重複量測區分系統誤差、隨機變異與樣品差異，避免只憑單次讀值下結論。
CASE FRAMEWORK 03

有機半導體薄膜與塗佈製程

薄膜／元件表現發生變化時，整理塗佈條件、溶液狀態、成膜特徵與量測結果間的假設鏈。

示意
01 / PROCESS製程條件
02 / FILM薄膜特徵
03 / DEVICE性能量測
04 / LINK關聯假設
查看分析框架
可觀察項目：溶液濃度與狀態、基板處理、轉速／塗佈速度、乾燥條件、膜厚／均勻性及元件量測。
驗證思路：先建立可重複的製程基準，再分段檢視製膜與元件指標，避免同時改動多個變因而無法歸因。
CASE FRAMEWORK 04

材料、製程與性能關聯分析

將複雜的品質問題轉化為可觀察變因，設計量測與記錄方式，建立可持續更新的異常分析架構；相關變因盤點方式也可作為氣體檢測訊號討論的起點，實際感測原理與限制仍須另行確認。

示意
01 / MAP盤點變因
02 / RECORD建立紀錄
03 / ANALYZE比對關聯
04 / REFINE調整流程
查看分析框架
可觀察項目：原料批次、設備條件、操作紀錄、環境參數、量測訊號與產品檢驗結果。
驗證思路：建立時間序列與異常事件記錄，從相關性提出候選原因，再透過可控測試確認；若證據不足，保留不確定性而不急於歸因。

MATERIALS SCIENCE建議撰寫主題

從材料微觀結構到宏觀性能：如何建立分析假設？

整理結構、界面、製程歷史與性能指標之間的可能關係，避免用單一表徵解釋所有現象。

預估閱讀 5 分鐘
展開筆記預告
規劃內容：定義待解釋的性能差異、列出可能的結構因素、辨識可觀察證據，並設計可以區分不同假設的量測或實驗。
PROCESS ENGINEERING技術筆記預告

製程優化不等於不斷調參：如何建立可用的製程視窗

由目標指標、設備限制、操作變因與可接受範圍出發，建立比單次最佳值更有用的製程理解。

預估閱讀 6 分鐘
展開筆記預告
規劃內容：區分控制因子與雜訊來源、確定量測回饋速度、記錄可行區間，再驗證製程在條件波動時是否仍能維持要求。
OPTICAL MEASUREMENT建議撰寫主題

量測數值可信嗎？從校正、重複性到判定門檻

拆解量測系統本身的變異，理解為什麼穩定的數據品質是異常判斷的前提。

預估閱讀 4 分鐘
展開筆記預告
規劃內容：用基準樣品觀察漂移、重複量測估計變異、辨識量測系統限制，最後再設定符合實際風險的判定規則。
SCIENTIFIC THINKING技術筆記預告

當數據不支持原本的想法：工程師如何修正假設

讓實驗結果可以推翻預期，並將不確定性與下一步驗證清楚記錄下來。

預估閱讀 5 分鐘
展開筆記預告
規劃內容：分開觀察與解釋、尋找替代假設、回頭檢查量測方法、設計反證測試；無法確定時明確標示未知條件。
